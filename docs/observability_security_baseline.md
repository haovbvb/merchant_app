# 可观测与安全基线（v1）

## 1. 可观测基线

- 日志分级：debug / info / warn / error
- 网络可观测：记录请求路径、耗时、状态码、错误类型（禁止记录敏感字段明文）
- 崩溃采集：统一异常上报接口，应用层可接入具体厂商 SDK
- 性能门槛：慢请求阈值默认 1500ms，超阈值写入告警日志

## 2. 安全基线

- 配置注入：环境配置通过构建参数或安全配置中心注入，不写入源码
- 敏感信息：Token、手机号、证件号、地理位置必须脱敏后再打印
- 证书策略：网络层预留证书绑定扩展点，默认关闭，可由应用启用
- 权限治理：仅在功能触发时按需申请权限，拒绝后提供明确引导

## 3. CI 安全检查建议

- 对变更内容做敏感信息扫描
- 对关键依赖做版本风险检查
- 对 release 分支强制执行全量质量门禁
